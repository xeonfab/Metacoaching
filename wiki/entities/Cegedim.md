# Cegedim

**Type**: Technical partner — HDS hosting provider
**Headquarters**: Boulogne-Billancourt, France
**MOC**: [MOC Méta-Coaching](../mocs/MOC_Metacoaching.md)

---

## Overview

French health IT company holding the **HDS (Hébergeur de Données de Santé)** state certification. Serves as Méta-Coaching's infrastructure and server hosting provider for all patient health data. This partnership is the core compliance mechanism enabling Méta-Coaching to legally store and process sensitive patient data (BMI, eating habits, sleep patterns, anxiety levels, addictive behaviors) under RGPD and French health code requirements.

---

## Relevance to the Mission

**Hard constraint**: Any automation or integration built on Make.com + Claude API must not route identifiable patient data outside the Cegedim HDS perimeter. Automation scope is restricted to operational/back-office data (aggregated KPIs, insurer reporting, email management, non-patient workflows).

See: [HDS concept page](../concepts/HDS.md)
