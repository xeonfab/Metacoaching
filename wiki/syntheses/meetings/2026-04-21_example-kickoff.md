## Context

This is a dummy synthesis page. It shows three things you'll do every time you ingest a source:
1. Reference the **entities** you met → [Example Person](../entities/Example_Person.md)
2. Reference the **concepts** you touched → [Example Concept](../concepts/Example_Concept.md)
3. Link back to the **raw source** in the Sources section below

## Key points

### Pattern — wiki is a web, not a tree
- Each page should link to 3-5 other pages minimum
- Backlinks are auto-generated by `python3 wiki/backlinks.py` → never edit the `Referenced by` block manually
- Claude uses these links to navigate — the denser the graph, the better the answers

### Pattern — raw stays raw
- The meeting transcript itself lives in `raw/transcripts/` and is **never edited**
- All interpretation, summary, re-framing happens here, in the wiki layer
